为什么大模型不能自己下结论

  • 模型事实恒为未核实。 workbuddy_llm_capture 只能输出 model_extracted / checked=false，不满足 eligible_for_hard()，无法触发硬排除或强关联规则。
  • Tool manifest 围栏。 PolicyGuard.validate_facts(..., tool_name=...) 按 tool.json 校验 allowed_fact_origins 与 facts_must_be_unchecked，伪装来源直接抛 PolicyViolation。
  • Skill 契约决定路由。 下一步动作来自 DecisionRouter + Skill ordered_queries，模型不参与决定调查顺序或终止条件。
  • 默认不授权。 两个本地采集 Tool 都不在默认 Policy.allowed_tool_names，只有显式 authorized_policy() 才启用。
  • 结论仍是草稿。 所有业务结论都是 DRAFT_NOT_APPROVED，不自动发送、不自动放行、不写回业务系统；证据不足时留空结论且不自动创建人工队列。
